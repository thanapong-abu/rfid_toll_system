HOW IT WORKS

01
📡

RFID Detected

Approaching vehicle's unique tag is scanned by the RC522 module via electromagnetic field.

02
🗄️

Database Validated

Python middleware securely cross-references the UID with the local SQLite database to verify funds.

03
🚦

Gate Actuates

Upon authorization, the SG90 servo lifts the barrier instantly and the transaction is permanently logged.
